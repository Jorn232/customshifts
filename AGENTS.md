# Onderhoud

- Dit is een openbare, statische codekopie van een privé-dashboard; de toepassing staat in `index.html` en heeft geen dependencies of buildstap.
- Behoud de Nederlandse interface, bestaande categorieën en vormgeving bij kleine functionele wijzigingen.
- Houd `chats` in deze openbare repository leeg. Commit geen privéchatlinks, gesprekstitels, samenvattingen, geheugenbestanden, credentials of Sites-configuratie.
- Lees eerst README.md en een gerichte diff; lees overige code alleen waar nodig. Vermijd herhaalde volledige analyses zonder gewijzigde input.
- Controleer JavaScript-syntaxis en de geraakte functie. Voeg voor kleine wijzigingen geen framework of testpakket toe.
- GitHub-commits publiceren niet automatisch naar de privé-Site. Neem codewijzigingen alleen gecontroleerd over met behoud van de privégegevens.
